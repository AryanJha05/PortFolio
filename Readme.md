## ✨ Features

- **Single-Page Architecture**: Seamless in-page navigation across Home, About, Skills, Projects, Achievements, Certifications, and Contact sections.
- **Fully Functional Contact Section**:
  - Direct email CTA points connected to `aryan42006@gmail.com`.
  - Structured 4-field contact form (**Name**, **Email**, **Subject**, **Message**).
  - Client-side validation with real-time feedback and RFC-compliant email checking.
  - Formatted `mailto:` trigger pre-populating recipient, subject, and sender information.
  - Accessible feedback alerts with direct send fallback links and raw email copy option.
- **Animations & Micro-interactions**:
  - GSAP timelines, text splitting animations, and ScrollTrigger-driven transitions.
  - Smooth page preloader with SVG curve transitions.
  - AOS (Animate on Scroll) reveal effects and interactive hover states.
- **100% Mobile Responsive**:
  - Fluid typography using CSS clamp.
  - Zero horizontal overflow across all screen sizes (320px mobile to 1920px+ ultra-wide).
- **Accessibility (a11y)**:
  - Accessible form labels, aria attributes, focus rings, and screen-reader polite alerts.

## 🚀 Running Locally

To preview or develop the portfolio locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/AryanJha05/PortFolio.git
   cd PortFolio/Portfolio1
   ```

2. **Serve with any static HTTP server**:
   - Using Python:
     ```bash
     python3 -m http.server 5500
     ```
   - Using Node.js `serve` / `http-server`:
     ```bash
     npx serve .
     ```
   - Or open `index.html` directly in any modern browser.

3. **Open in browser**:
   Navigate to `http://localhost:5500`.
